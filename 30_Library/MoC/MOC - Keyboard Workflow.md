## MOC - Keyboard Workflow

This Map of Content serves as the primary entry point for understanding the globally consistent, keyboard-driven workflow used across this system.

### Core Philosophy

> [!definition] Scope by Modifier
> The system is designed so you never have to guess "What key does what?". The modifier key determines the scope of the action, creating a predictable, hierarchical control scheme.
