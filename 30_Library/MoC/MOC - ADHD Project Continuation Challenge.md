## Minimum Viable Understanding (MVU)

The "Project Return Problem" is a collision between Working Memory deficits (Mental Model Dissipation) and Novelty-Seeking (Dopamine drops when a project is no longer "new"). To continue, one must externalize the volatile mental model into stable "scaffolding" and create low-friction re-entry points that bypass the need for an immediate dopamine hit.

---

## 1. The Core Tension: The Fresh Start Loop

[[ADHD Causes Deficits in Completing Long-Term Projects]]

- The Flow State: When active, the mental model is a vivid, high-resolution internal map. It feels "complete" and rewarding.
- The Dissipation: Upon stopping, the model evaporates. Returning feels "flat" because the context is gone and the novelty is depleted.
- The Maladaptive Response: Starting a _new_ project (or refactoring the current one from scratch) provides a fresh dopamine hit and a clean mental model, leading to the abandonment of previous work.

---

## 2. Strategies for Scaffolding Continuity

### A. Externalize the Volatile Model

Capture the "HEAD" state before it dissipates.

- [[Documenting Mental Models Enables Project Re-entry]]: Use mind maps, voice memos, or "The Future Self Brief" to record the _why_ and the _vision_, not just the _what_.
- The Future Self Brief: A 10-minute wrap-up note recording current excitement, key decision points, and "unfinished threads."

### B. Create Low-Friction Re-entry

Lower the activation energy required to move from "Off" to "On."

- [[Breaking Projects Into Micro-Tasks Reduces ADHD Overwhelm]]: Decompose until the next action is binary (Done/Not Done).
- [[The Hemingway Technique - End Work With Unfinished Problems]]: Stop mid-sentence or mid-function. Leave a "broken" state that is obvious and easy to fix.
- [[A Project Playlist is a Sequence of Small Tasks to Rebuild Momentum]]: A curated 3-5 task list of "shallow" wins to rebuild the mental model.

### C. Build Rituals & Environment

Use external cues to trigger the "Project Identity."

- [[Continuation Rituals Bridge Work Sessions for ADHD]]: A consistent "Startup Ritual" (specific music, workspace, or review of the Project Story).
- [[Visual Schedules Make Routines Tangible]]: Keep the project's "Logic Map" or high-level diagram physically visible in the workspace to reignite the connection.
- [[Exit Ritual For ADHD Time Boxes]]: A hard stop that includes defining the _exact_ physical next action.
