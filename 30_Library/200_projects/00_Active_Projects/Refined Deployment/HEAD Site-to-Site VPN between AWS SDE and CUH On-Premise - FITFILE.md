## Project Plan: Site-to-Site VPN between AWS SDE and CUH On-Premise

Objective: To establish a secure, private, and compliant Site-to-Site VPN connection, enabling bidirectional communication between the AWS Secure Data Environment (SDE) and the on-premise CUH network.

Key Teams:

- AWS Team: Responsible for the AWS central hub configuration.
- CUH Team: Responsible for the on-premise FortiGate firewall configuration.
