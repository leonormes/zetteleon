## 1. Goal: Minimize Context Switching Cost

Interrupted work sessions are expensive for the ADHD brain. Restoring the "Save State" (variables in working memory) requires significant energy. The **Hemingway Bridge** ensures a low-friction re-entry point for the "Future Self."

---

## 2. The Mandate: Never Finish Completely

- **The Rule:** NEVER finish a task completely during a session.
- **The Protocol:** Leave the very last, easiest step (e.g., typing the last word, running the final test) for the *next* session. This provides an immediate "momentum hook."

---

## 3. The "Save State" Note Specification

At the end of every work block or when an interruption occurs, perform a **Save State Commit** using this format:

- **Timestamp:** Logging the stop time.
- **Current Context:** A summary of the "Working Tree" (what was just done).
- **Next Micro-Step (MVA):** Explicit, kinetic instruction for re-entry (e.g., "Open file X and run command Y").
- **Mood/Energy:** Log emotional state to help the Future Self empathize with the context.

---

## 4. Usage: Interstitial Journaling

Use the hashtag `#SAVESTATE` within your Interstitial Journal or Daily Note. This creates a breadcrumb trail, allowing you to retrace your steps if distracted.

> "Stopping at Step X. Next step is Y. Feel tired but satisfied."
