# SoT - PRODOS - Learning Architecture

> [!definition] Core Philosophy
> **We do not "study" topics. We attack them.**
> Learning is not the passive accumulation of data; it is the **active reconfiguration of neural architecture**. To learn is to build.
> *   **Golden Rule:** **No Input without Output.** Consumption without creation is strictly forbidden.
> *   **The Metric:** Not "hours studied," but **"Unit Tests passed."**

---

## 1. Phase I: The Hangar (Architecture & Compression)

*Goal: Define the Territory and Compress the Signal. Do not fly without a Flight Plan.*

### 1.1 Safety Check (Pre-Flight)
*   [ ] **Interest Check:** Is this a dopamine spike or a genuine resource commitment? (See: `SoT - ADHD Neurology`).
*   [ ] **MVA:** Create HEAD Note (`YYYY-MM-DD-HHmm-HEAD - Learning [Topic]`).

### 1.2 Protocol: The Ingestion Engine (NotebookLM)
Do not read 50 PDFs. Use AI to compress the noise.
1.  **Ingest:** Upload all PDFs/URLs to a specific Notebook.
2.  **Compress (3C):** Run the **Architect Prompt** to generate a Syllabus.
    *   *Prompt:* "Analyze these sources. Create a syllabus split into **Concepts** (Mental Models), **Facts** (Memorization), and **Procedures** (Skills)."
3.  **The Capstone:** Define the "Boss Fight" (e.g., "Build a Traffic Light Controller in Rust"). You are not done until this exists.

### 1.3 Error Handling (Initiation Paralysis)
*   *Signal:* "This is too big. I don't know where to start."
*   *Fix:* **The Starter Task.** Do not "start learning." Just **"Create the Folder"** or **"Upload one PDF."**

## 2. Phase II: The Cockpit (Execution & Compilation)

*Goal: High-Velocity Iteration. Fail fast, fail often.*

### 2.1 Safety Check (Takeoff)
*   [ ] **Environment:** Phone in "Cold Zone." Timer set to **45m**.
*   [ ] **MVA:** Open the IDE/Editor. Read the **Bridge Note**.

### 2.2 Protocol: The Oakley Hard Start (Deep Dive)
Replace linear reading with cyclical failure.
1.  **The Probe (0-5m):** Attempt the **Unit Test** immediately *before* reading the theory.
    *   *Why:* Failure loads the problem into Working Memory (The Generation Effect).
2.  **The Diffuse Retreat (5-20m):** If stuck, step back. Read the specific documentation/chapter needed to fix *that specific error*.
3.  **The Attack (20-45m):** Apply the fix. Write the code.
4.  **The Critique:** Paste result into LLM with **Hostile Compiler Prompt**.

### 2.3 Tactics: Active Learning (The Peter Method)
Never copy-paste.
*   **Feynman Technique:** Explain the concept to an empty chair in simple language.
*   **The Peter Method:** Read -> Look Away -> Write Summary -> Compare.

### 2.4 Error Handling (Focus Drift)
*   *Signal:* "I'm bored/distracted."
*   *Fix:* **Dopamine Menu (Appetizer).** Stand up. Do 20 Jumping Jacks. Re-engage.

---

## 3. Phase III: Cryosleep (Consolidation & Storage)

*Goal: Persistence and Context Preservation.*

### 3.1 Safety Check (Landing)
*   [ ] **Stop:** Timer ends. Do not continue (respect the cycle).

### 3.2 Protocol: The Hemingway Bridge
Minimize the cost of re-entry for the Future Self.
1.  **The Save State:** Write a **Bridge Note** at the top of the HEAD file.
    *   *Current State:* "Function X is broken."
    *   *Next Physical Action:* "Google Error Y."
2.  **The Hook:** Leave the "easy win" unfinished to pull you back in.

### 3.3 Protocol: Neural Consolidation
1.  **Micro-Rest:** 10s of doing nothing after a breakthrough.
2.  **Macro-Rest:** 20m **NSDR** (Non-Sleep Deep Rest) or a nap to wire the new circuits.

### 3.4 The Merge (Definition of Done)
When the Capstone is built:
1.  **Synthesize:** Compress the HEAD note into an atomic **SoT Note**.
2.  **Archive:** Move HEAD note to `99_Archive`.

- [ ] **Merge:** (Final) Created SoT Note and Archived HEAD.
