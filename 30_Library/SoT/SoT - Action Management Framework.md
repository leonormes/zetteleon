## SoT - Action Management Framework

> **Core Question:** How do we transform abstract intent into concrete reality?

This Source of Truth (SoT) provides the complete framework for managing action within the ProdOS ecosystem. It is designed to counter **ADHD Task Initiation Deficits** by creating a robust system that separates thinking from doing and transforms vague intentions into executable steps.

---

### 1. The System (The How)

This section defines the canonical workflow for managing actions.

- **[[SoT - PRODOS - Action Management (GTD)]]**: The primary workflow, detailing the 4-phase process: **Capture -> Refine -> Bridge -> Engage**.
- **[[SoT - PRODOS - The Cognitive Loop (A-C-T Framework)]]**: The theoretical model of how Action (A), Context (C), and Thought (T) interact.

**Key Principles of the System:**
- **Separation of Concerns:** Thinking and planning occur in Obsidian. Executable tasks live *only* in a dedicated task manager (e.g., Todoist). This prevents the "list of lists" problem and reduces cognitive load.
- **Context Preservation:** Every action in the task manager must link back to its originating context in Obsidian (The Context Bridge). This solves the "What was I thinking?" problem when returning to a task.
- **LLM-Powered Refinement:** Vague ideas are "linted" and refined into atomic actions *before* they are sent to the task manager.

---

### 2. The Atomic Unit (The What)

The fundamental building block of all productive work is the **Atomic Action**. This is the answer to the question: "What is the very next physical thing I need to do?"

- **Core Principle:** [[The Action is the Atomic Unit of Productivity]]. It transforms vague intent into tangible progress.

#### The Four Essential Properties of an Atomic Action
An atomic action (or "Next Action" in GTD) must satisfy four properties to be valid, as defined in [[Atomic Actions Have Four Core Properties]]:
1.  **Indivisible (Atomic):** It cannot be broken down further. "Write report" is not atomic; "Open Google Docs and create a new document titled 'Q4 Report'" is.
2.  **Physical & Visible:** It must be a real-world activity that produces an observable change.
3.  **Unambiguous Definition of Done:** [[Atomic Action Completion Must Be Binary and Instantly Verifiable|Completion is binary (0 or 1)]]. You either did it or you didn't. There is no "almost done."
4.  **Context-Specific:** [[Atomic Actions Are Context-Specific|It is tied to a specific tool, location, or person]] (e.g., `@computer`, `@phone`, `@office`).

#### Context Organization
[[Context Tags Make Actions Location and Tool Specific|Context tags]] are the organizational layer for actions. They allow for efficient batching, reduce context-switching, and filter tasks to what is currently possible. For ADHD, [[Contexts Reduce Overwhelm and Support Working Memory for ADHD|contexts are critical for reducing overwhelm]] by showing only what is relevant now.

#### Composing Actions into Projects
Individual actions are composed into larger projects, which can be modeled as [[Action Sequences Form Directed Acyclic Graphs|Directed Acyclic Graphs (DAGs)]]. This means a project can have [[Projects Can Have Multiple Parallel Action Sequences|multiple parallel sequences of actions]].

### 3. The Neurology (The Why)

Understanding the neurological barriers to action, especially in ADHD, is key to designing a system that works.

- **Dopamine Dysregulation:** [[ADHD Causes Task Initiation Deficits Due to Dopamine Hyposensitivity|ADHD is characterized by dopamine hyposensitivity]], which means the brain requires higher stimulation (novelty, urgency, interest) to initiate tasks. This leads to the "Wall of Awful."
- **Network Switching:** The brain struggles to switch from the "thinking" state (Default Mode Network, DMN) to the "doing" state (Task Positive Network, TPN). An external, trusted system helps force this switch.
- **Activation Energy:** [[Activation Energy is the Primary Barrier to ADHD Task Initiation|Activation Energy is the primary bottleneck]]. Our system's goal is to lower this barrier as much as possible.

---

### 4. The Strategies (The Fix)

These are techniques to lower activation energy and trigger action.

#### For Initiating Difficult Tasks (The Momentum Method)
- **[[SoT - Starter Tasks|Starter Tasks]]:** A special class of atomic action designed *only* to build momentum. They follow three rules: momentum as the only purpose, 5-15 minute max duration, and must be a single physical action. They are a direct counter to high activation energy.
- **Artificial Ignition:** As detailed in [[SoT - Bridging the Intention-Action Gap]], this involves manufacturing dopamine through **Mystery** (framing a task as an experiment), **Urgency** (time-boxing), or **Spite** (proving something wrong).

#### For Converting Thoughts into Actions (The Clarification Process)
- **[[Clarifying Stuff Into Actions Follows a Four-Step Process|The Four-Step Clarification Process]]** converts vague thoughts ("Stuff") into clear, atomic actions. This process externalizes decision-making and is a core part of the GTD "Clarify" phase.
- **Motion vs. Action:** It is critical to [[The Skill in Productivity is Not Confusing Motion for Action|distinguish preparatory "motion" from productive "action"]]. Organizing and planning are motion; executing a next action is action. Motion can be a form of productive procrastination if not managed.
