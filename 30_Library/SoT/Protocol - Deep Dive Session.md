## Protocol: Deep Dive Session V1.1

> [!abstract] Purpose
> To maximize "information gain" using the **Oakley Hard Start Algorithm**. This replaces linear study with a cycle of "Focus" (Head-On) and "Diffuse" (Background Processing).

### The Algorithm

#### Phase 1: The Oakley Hard Start (00:00 - 05:00)

*Do not start by reading. Start by failing.*

- [ ] **The Probe:** Immediately attempt the hardest problem in your specific Timebox (e.g., "Write the Worker Pool implementation from scratch").
- [ ] **The Struggle:** Push until you hit a wall. Feel the frustration. This loads the problem into working memory.
- [ ] **The Pivot:** If stuck after 5 minutes, **STOP**. Do not brute force it yet.

#### Phase 2: The Diffuse Retreat (05:00 - 25:00)

*Let the background brain process the Hard Start while you keep moving.*

- [ ] **Switch Context:** Move to a "Mechanical Drill" or "Easy Win" defined in your Failure Mode plan.
    - *Example:* Flashcards, Syntax Drills, Setting up the IDE, reading the "Introduction" chapter.
- [ ] **The Goal:** Build momentum and dopamine while the subconscious works on the "Hard Problem."

#### Phase 3: The Return (25:00 - 45:00)

*Return to the Hard Problem with fresh eyes.*

- [ ] **Re-Engage:** Go back to the problem from Phase 1.
- [ ] **The Breakthrough:** You will often find the solution is now obvious or you have a new angle.
- [ ] **Execute:** Write the code / Draw the diagram / Solve the equation.

#### Phase 4: Feynman Exit (45:00 - 50:00)

*Mandatory Synthesis. If you can't explain it, you didn't learn it.*

- [ ] **The Prompt:** Open the `Curriculum Note` -> `Synthesis Queue`.
- [ ] **The Explanation:** Write a simple, jargon-free explanation of the core concept.
    - *Constraint:* No technical terms allowed in the first sentence.
- [ ] **The Transfer:** If the explanation is solid, move it to the **Source of Truth (SoT)** note.

#### Phase 5: The Shutdown Ritual (Newport)

*Clear the context to prevent "Attention Residue".*

- [ ] **Close Loops:** Close all browser tabs and IDE windows.
- [ ] **Next Action:** Write the specific Drill/Task for the *next* session in the Curriculum Note.
- [ ] **The Phrase:** Say aloud: **"Shutdown Complete."**
