## Software as Specification (Ghost Libraries)

Software distribution is shifting from providing pre-written, compiled code libraries to providing high-level specifications ("ghost libraries") that local agents implement and assemble according to environment-specific requirements. This model allows for the dynamic generation of logic that is perfectly tailored to the local tech stack and runtime environment.

### Scope & Conditions

Associated with the Symphony framework and "extreme harness engineering" paradigms.

### Evidence

> "This model moves away from distributing traditional code libraries. Instead, software is shared as a 'spec' (or 'ghost library'), which a local agent then implements and reassembles."

### Implications

- Eliminates many common environmental dependency conflicts by generating code that matches the local environment.
- Reduces library bloat and unused dependencies by implementing only the logic relevant to the specific use case.
