## Superseded

This note bundled four distinct claims and conflated working memory with executive function in general. It was split on 2026-11-18 into four atomic cards:

- **Core claim (working memory scope):** [[A trusted, always-available external task scaffold performs the working-memory function for an ADHD person for the operations it holds, rather than assisting an internal one]]
- **Generic coupling conditions:** [[An external structure counts as part of a cognitive process only if it is constantly available, easily accessible, and automatically trusted]]
- **Diagnostic counterfactual:** [[Removing a constitutive scaffold stops the operation while removing an assistive one only slows it]]
- **ADHD capacity hypothesis (unsourced):** [[ADHD raises the share of operations that exceed unaided working-memory capacity, so more scaffolds become constitutive]]
