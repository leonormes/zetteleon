## Digital Tools Help Externalize Memory and Structure for ADHD Developers

Summary: A variety of digital tools can help software developers with ADHD by externalizing memory, providing structure, and automating routine tasks. [implements:: [[SoT - Prosthetic Executive Function]]]

Details: These tools can be categorized to address specific needs:
- Task managers (Trello, Todoist) provide visual organization and [implements:: [[External Structure and ADHD]]]. 
- AI planners (Saner.AI, Motion) reduce cognitive load by auto-scheduling tasks, which [supports:: [[Structure conserves cognitive energy for neurodivergent brains]]].
- Focus apps (Forest, Self Control) combat time blindness and block distractions, which [depends_on:: [[Time Agnosia Impairs Planning for Developers with ADHD]]].
- Sensory control apps (Brain.fm) and noise-canceling headphones create a conducive environment. 
- Automation tools (TextExpander) save cognitive energy on repetitive tasks.
- Virtual co-working platforms (Focusmate) provide accountability.

All of these strategies follow the principle to [extends:: [[Externalize Memory Aggressively (cognitive offloading)]]].
