## How the Brain Learns Core Cognitive Processes

Learning in any domain runs through three linked processes: attention selects what gets in, perception organises it into something meaningful, and memory stores it and makes it retrievable. Each stage constrains the next, so a weakness early in the chain limits everything after it.

### Scope & Conditions

This is a framework note, not a claim to be proved. It is domain-general, with software development as the worked example through [[Foundations of Learning and Cognition for Developers]]. The three-stage ordering is a useful simplification: in practice the stages loop, because what is already stored shapes what is attended to and perceived.

### Evidence

This framework is my own synthesis of the notes linked below, not a quotation from a single source. The supporting quotations live in those notes and in [[Evidence - Levitin Says Attention Is a Limited-Capacity Resource With Definite Limits]].

### Implications

- Protecting attention is a precondition for learning, not a productivity extra.
- Study design should reduce load at the perception stage so that working memory is spent on meaning.
- Retrieval, spacing and use matter as much as first exposure, because storage is not the same as recall.
