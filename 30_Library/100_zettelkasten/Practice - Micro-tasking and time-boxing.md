## Practice—Micro-tasking And Time-boxing

What: Break tasks into the smallest workable units and run them inside a fixed time box (e.g. a Pomodoro), rather than facing the whole task as one block.

Why it suits ADHD: A tiny first unit lowers activation energy; the time box harnesses hyperfocus while capping it before burnout; each completed box gives immediate, motivating feedback.

Micro-step: Take the task you are avoiding and write down only its first physical action (verb-plus-object, e.g. "open the file"). Do not do it yet—just name it.
