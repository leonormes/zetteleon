Definition: Emergence refers to the phenomenon where complex patterns, behaviors, or properties arise from the interactions of simpler components, which cannot be predicted by analyzing the components alone.

- Context: Emergence is a key concept in fields like systems theory, complexity science, biology, and network theory.
- Example: John Conway's Game of Life is a classic illustration of emergence from simple rules in a system of cellular automata.

## Two Senses of Emergence

The definition above is the strong, predictive sense: the pattern cannot be predicted from the parts. Two other treatments in the library separate it from a weaker, practical sense.

- Effective description (Carroll). "A property of a system is "emergent" if it is not part of a detailed "fundamental" description of the system, but it becomes useful or even inevitable when we look at the system more broadly." The higher-level description is indispensable in practice, while nothing is added to the physics. See the Evidence note below and [[Newtonian Physics as an Effective Theory]] for the same move in physics.
- Predictive versus explanatory (Deutsch). "'emergence' in the standard sense is only one way in which explanations in different strands may be related. So far I have really only considered what might be called predictive emergence." He contrasts this with explanatory emergence, where a higher-level explanation stands on its own and is not derived from the level below.

Which sense a note means matters: the strong sense supports claims about irreducibility, the weak one only claims usefulness.
