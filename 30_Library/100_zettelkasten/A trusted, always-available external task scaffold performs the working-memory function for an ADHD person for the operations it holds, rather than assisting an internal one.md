## A trusted, always-available external task scaffold performs the working-memory function for an ADHD person for the operations it holds, rather than assisting an internal one

For a given operation, if an external task scaffold is constantly available, easily accessed, and automatically trusted, it is functionally part of the ADHD person's working memory for that operation rather than an aid to an internal store. Scope is strictly working memory and the operations offloaded, not executive function in general. ^claim

### Scope & Conditions

- **Working memory only:** A task scaffold holds and cues operational state; it does not inhibit, shift, or plan on its own.
- **Generic coupling conditions:** Constitutive status requires constant availability, easy access, and automatic trust ([[An external structure counts as part of a cognitive process only if it is constantly available, easily accessible, and automatically trusted]]).
- **Initiation boundary:** Holds active operational state once entered; passive scaffolds still fail at ignition without an external push floor ([[External Scaffolds Fail Through Circularity When They Require Executive Function to Operate]]).

### Evidence

> "The external task scaffold IS the executive function for an ADHD cognitive system. The vault IS the externalised prefrontal cortex. The scaffold does not help with working memory—it is the working memory for that operation. Removing it does not make things harder; it removes the faculty."
> ([[SoT - Structure is Truth is a Unifying Axiom Across Formal Systems]], §2, Cognitive Scaffolding row—overreaches on "executive function" and "prefrontal cortex"; narrowed here to working memory)

- **Internal bottleneck:** Fragile working memory in ADHD forces operational state outward to avoid mid-task thread loss ([[ADHD Working Memory Deficits Create a Compulsive Re-Planning Loop]], [[Writing Acts as an External Working Memory]]). *(No direct Calibre book quotation attached yet.)*

### Implications

- **Testable boundary:** Distinguishes constitutive scaffolds from mere aids via [[Removing a constitutive scaffold stops the operation while removing an assistive one only slows it]].
- **Why ADHD relies on it more:** Motivation for why more daily operations cross the threshold sits in [[ADHD raises the share of operations that exceed unaided working-memory capacity, so more scaffolds become constitutive]].
