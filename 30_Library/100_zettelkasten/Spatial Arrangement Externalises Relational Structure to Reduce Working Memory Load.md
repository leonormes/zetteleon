## Spatial Arrangement Externalises Relational Structure to Reduce Working Memory Load

Spatial layouts reduce cognitive load by replacing internal sequential processing with perceptual structure, shifting relational work from internal memory onto the environment (Zhang and Norman, 1994). This combines with Dual Coding Theory's two-channel encoding (verbal plus imaginal) to produce stronger, more retrievable memory traces than linear text alone.

### Scope & Conditions

Particularly consequential for individuals with limited working memory capacity, where executive-function depletion is a primary bottleneck; the offloading is operationally necessary, not merely convenient.

### Evidence

> "Spatial arrangements externalise relational structure, reducing the demand on working memory (executive function) for holding that structure internally… For neuro-variable individuals with limited working memory capacity, this offloading is not merely convenient but operationally necessary."

### Implications

- Visual node maps activate both the verbal system (labels) and the imaginal system (spatial arrangement), which linear text cannot do alone.
- For ADHD or limited-working-memory profiles, spatial offloading directly reduces the rate of executive-function depletion during synthesis work.
