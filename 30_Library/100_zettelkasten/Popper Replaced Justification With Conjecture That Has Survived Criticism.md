## Popper Replaced Justification With Conjecture That Has Survived Criticism

Popper rejected justificationism outright. For him knowledge is conjecture that has survived criticism, not justified true belief. The question about any belief then changes from "is it justified?" to "is it open to criticism or refutation?".

### Scope & Conditions

This is a secondhand report from an AI chat, not read from Popper. The chat's point about the vault is that a Popperian system conflicts with the traditional definition if that definition is the working one, and is fine if it is only a historical reference point. [[The Traditional Definition of Knowledge is Justified True Belief]] already records this as a tension through the Deutsch notes, but no note states the Popperian position directly until this one.

### Evidence

> "Your Zettelkasten is Popperian, and Popper rejected justificationism outright. For him, knowledge is conjecture that has survived criticism, not justified true belief."
> (AI chat transcript pasted by Leon, 2026-10-23, section "Is there knowledge about God, or only belief?")

> "Under Popper the question changes. It is no longer “is belief in God justified?” but “is the God hypothesis open to criticism or refutation?”"
> (same section)

> "For Popper, everything is conjecture, including “electrons exist”."
> (section "Ghosts, fairies, and knowing that something doesn’t exist")

### Implications

- The useful line is not know versus believe but well-corroborated, untested and untestable, which is the chat's own table.
- It leaves the working definition of knowledge in this vault to be decided: justified true belief, or surviving criticism.
