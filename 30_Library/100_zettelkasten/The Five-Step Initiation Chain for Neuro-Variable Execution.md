### The Five-Step Initiation Chain for Neuro-Variable Execution
An initiation chain for bypassing ADHD task-paralysis sequences five stages: (1) a pre-task somatic trigger priming DLPFC activation, (2) an environment-linked if-then plan that automatically triggers the opening action, (3) a zero-calculation first physical action requiring no decomposition at execution time, (4) an immediate visible feedback loop that produces a perceptible state change and generates a reward-prediction-error signal, and (5) temporal boundary acceptance, in which the session has a predefined end that decouples execution from the anxiety of infinite obligation.

#### Scope & Conditions
Designed as a synthesis chain combining somatic, environmental, and cognitive-architecture interventions rather than any single technique in isolation. Each stage addresses a distinct failure point identified elsewhere in this research: DLPFC priming, TPN/DMN transition, next-action decomposition, RPE-driven motivation, and finitude-anxiety decoupling.

#### Evidence
> "1. Pre-task somatic trigger... 2. Environment-linked if-then plan... 3. Zero-calculation first action... 4. Immediate visible feedback loop... generating an RPE signal... 5. Temporal boundary acceptance."

#### Implications
- Use as a checklist immediately before starting a technical task that is triggering avoidance: movement, then a specific cue-triggered opening action, then a single zero-decision first step, then note the visible output, then set an explicit session end time.
- Each stage can fail independently — diagnosing which stage is missing is more useful than treating "I can't start" as one undifferentiated problem.
