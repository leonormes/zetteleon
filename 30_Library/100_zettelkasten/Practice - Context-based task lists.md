## Practice—Context-based Task Lists

What: Group tasks by current context—location, tool to hand, energy level (e.g. _phone calls_, _errands_, _computer_)—rather than only by project.

Why it suits ADHD: Cuts decision fatigue by matching the list to what you can actually do right now, so choosing the next action is near-automatic instead of a fresh deliberation.

Micro-step: Create one list called "Calls" and move a single existing task onto it.
