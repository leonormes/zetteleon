## Sweller's Three Cognitive Load Types Must Be Balanced in Any Knowledge System

John Sweller's Cognitive Load Theory identifies three distinct types of cognitive load a learning or knowledge-management environment must balance: intrinsic load (the inherent difficulty of the subject matter), extraneous load (load generated by how information is presented, e.g. poor interfaces or unnecessary admin tasks), and germane load (effort dedicated to constructing and automating cognitive schemas in long-term memory).

### Scope & Conditions

A system that focuses on storage rather than sensemaking maximises extraneous load and minimises germane load.

### Evidence

> "Sweller identifies three types of cognitive load that must be balanced in any learning or knowledge management environment."

### Implications

- Elaborate folder structures and over-formalisation are extraneous load, not intrinsic complexity.
- A PKM system should be evaluated by whether it maximises germane load (forcing active relation of new to existing concepts), not by how much it stores.
