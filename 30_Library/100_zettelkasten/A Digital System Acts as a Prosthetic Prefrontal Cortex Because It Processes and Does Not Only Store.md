## A Digital System Acts as a Prosthetic Prefrontal Cortex Because It Processes and Does Not Only Store

A digital system such as this vault acts as a prosthetic prefrontal cortex because it is used for processing and not only for storage. ^claim

### Scope & Conditions

Digital systems as cognitive tools, the fourth dimension. It holds only while the system is reliable and the interface is frictionless.

### Evidence

This is my own summary of the thesis as set out in the earlier text of [[SoT - The Extended Mind]], which attributes it to Clark and Chalmers. No book quotation has been verified for this card.

### Implications

- Judge a tool by what thinking it supports, not by how much it holds.
