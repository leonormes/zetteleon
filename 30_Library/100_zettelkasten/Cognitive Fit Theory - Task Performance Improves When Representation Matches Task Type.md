## Cognitive Fit Theory - Task Performance Improves When Representation Matches Task Type

Iris Vessey's Cognitive Fit Theory (1991) holds that problem-solving performance is enhanced when there is a match between the information emphasised by a representation type and the information required by the task type. Graphical or spatial representations emphasise relational information that can be apprehended perceptually, while tabular or symbolic representations require that relational structure to be analytically constructed in working memory.

### Scope & Conditions

Applies specifically to "spatial tasks"—those requiring comparison of values or identification of relationships—which benefit from graphical representation because it externalises relational structure onto the perceptual system.

### Evidence

> "Vessey's core proposal is that performance on a problem-solving task is enhanced when there is a match (cognitive fit) between the information emphasised by the representation type and the information required by the task type."

### Implications

- Forcing a relational-understanding task (e.g. "how do these concepts connect?") into linear markdown text imposes unnecessary cognitive load, because the reader must internally construct the relational structure the representation should have externalised.
- Choose graph or canvas views for relational-synthesis tasks and linear text for sequential-argument tasks—the representation should be selected by task type, not by habit.
