## Memory Enables Learning by Storing Experiences for Future Use

Learning means changing behaviour because of past experience, and that is only possible if some trace of the experience persists. Memory is therefore a precondition for learning, and one of the core tools in the problem-solving toolbox.

### Scope & Conditions

Memory here means any persistence of information about past experience, not only neural memory. The claim is about the dependency of learning on storage, not about how good or how durable the storage is.
