## Project-Level Rule Standardisation

Standardizing project rules in files like `agents.md` (or `.cursorrules`) ensures that AI agents operate within established repository conventions. These files automate the enforcement of build commands, testing requirements, and styling standards, maintaining consistency between human and agent-generated code.

### Scope & Conditions

Repository-level configuration for AI assistants. It acts as a "living contract" for autonomous contributors.

### Evidence

> "The use of agents.md as a de-facto standard for project-level rules… ensures that agents operate within established repository conventions."

### Implications

- Automates the enforcement of build, test, and style requirements.
- Maintains consistency between human-written and agent-generated code.
