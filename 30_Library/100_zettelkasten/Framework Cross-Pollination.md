## Framework Cross-Pollination

Specialized optimization frameworks, even those built for specific domains like machine learning, can be effectively adapted for general tasks through iterative AI-human collaboration. By using an LLM to refactor the logic and re-contextualize the evaluation criteria, developers can bypass ground-up tool development.

### Scope & Conditions

Repurposing specialized or legacy tools for novel domains. Success depends on the human's ability to communicate the new domain's rules to the AI collaborator.

### Evidence

> "you will need to collaborate with Claude to adapt it for your specific use cases."

### Implications

- Bypasses the need for ground-up tool development.
- Requires high-level prompting to refactor legacy code for new contexts.
