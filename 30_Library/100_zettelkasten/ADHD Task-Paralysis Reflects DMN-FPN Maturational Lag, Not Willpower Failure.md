## ADHD Task-Paralysis Reflects DMN-FPN Maturational Lag, Not Willpower Failure

ADHD task-paralysis reflects partial co-firing of the default mode network (DMN) and the task-positive network (TPN), not a failure of willpower. The co-firing arises from diminished DMN-TPN anticorrelation and a maturational lag in DMN connectivity to the frontoparietal network (FPN), so the brain reaches neither full task engagement nor full DMN suppression. ^claim

### Scope & Conditions

The supporting data are resting-state fMRI correlations in ADHD samples, which show the network pattern but not that it causes task-paralysis. The source's "direct cause" wording is an inference. The FPN is implicated because it generates task-control signals for unpractised situations, so immature connectivity would impair configuring the brain for a new task on demand. The claim is weakened if task-paralysis severity does not track DMN-FPN connectivity within ADHD samples. It competes with a switching-failure account of the same symptom, see Tensions.

### Evidence

> "ADHD is characterised by diminished anticorrelation, including increased DMN–VAN connectivity and DMN–FPN maturational lag… Task-paralysis is a direct consequence of partial co-firing: neither full TPN engagement nor full DMN suppression is achieved."
> (Neuro-Variable Execution, Spatial Cognition & Knowledge Architecture - An Investigative Report, section not recorded)

The same report cites the ADHD-200 sample (n=757) and multi-site resting-state studies. These were not traced to primary papers here, so the claim rests on a secondary report.

### Implications

- Task-paralysis is better treated as a measurable network-topology constraint needing environmental and behavioural workarounds than as a motivation problem solved by willpower or guilt.
- Interventions should target the transition into TPN-dominant states directly, for example somatic triggers and implementation intentions, rather than suppressing DMN rumination through effort alone.
