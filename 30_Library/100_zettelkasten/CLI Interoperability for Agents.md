## CLI Interoperability for Agents

Effective agent integration relies on small, interoperable command-line tools that follow the Unix philosophy, allowing agents to pipe data between various services such as GitHub, Sentry, and project management tools. This modularity reduces reliance on monolithic GUIs and enables automated cross-platform task execution.

### Scope & Conditions

Based on the Unix philosophy of modular tooling. It applies to the design of development environments where AI agents are expected to orchestrate workflows across multiple systems.

### Evidence

> "Effective agent integration relies on the 'Unix philosophy'—small, interoperable tools and Command Line Interfaces (CLIs) that allow agents to pipe data between services."

### Implications

- Facilitates automated cross-platform task execution.
- Reduces reliance on monolithic GUIs for agentic work.
