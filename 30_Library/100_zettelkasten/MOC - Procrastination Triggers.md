## MOC - Procrastination Triggers

An entry point from three personal observations about what triggers procrastination, mostly around mundane tasks that lack immediate reward or interest, to the notes that explain each one. Start with whichever quotation matches the stuck moment.

> Procrastination and task initiation are not quite the same problem. [[The Neurological Divide Between Procrastination and Task Initiation]] separates a mechanical failure to switch focus from an emotion-regulation response.

---

### Trigger 1: A Short Task Offers No Reward

> "Why don't I do the dishes? It's as if doing a short one-off task like that doesn't offer any dopamine rewards. I like things to be clean and tidy. I don't get anything from the dishwasher."

- [[The 'Dopamine Shot' vs 'Relief from Anxiety' in Task Completion]]—finishing an unpleasant task may bring only relief, not satisfaction. [synthesizes:: [[The 'Dopamine Shot' vs 'Relief from Anxiety' in Task Completion]]]
- [[Dopamine reward pathway dysfunction causes ADHD task initiation difficulty]]—the proposed reward-system mechanism. [synthesizes:: [[Dopamine reward pathway dysfunction causes ADHD task initiation difficulty]]]
- [[SoT - The Interest-Based Nervous System in ADHD]]—why interest moves action when importance does not. [synthesizes:: [[SoT - The Interest-Based Nervous System in ADHD]]]

### Trigger 2: No Energy, No Motivation

> "My motivation is so tied to my feelings. It sounds simple. But I really do need that energy in my brain. Motivation seems to be dependent on it. I'm almost paralyzed without it."

Starting can ask for more mental energy than is available, a barrier between not doing and doing.

- [[MOC - Why Task Initiation is Difficult in ADHD]]—the wider map of why activation fails. [extends:: [[MOC - Why Task Initiation is Difficult in ADHD]]]
- [[SoT - The Cognitive Physiology of Task Execution]]—the initiation phase and the Wall of Awful. [extends:: [[SoT - The Cognitive Physiology of Task Execution]]]
- [[SoT - Working Memory & Schema Theory]]—the load of holding and managing many small tasks.
- [[Executive Function Deficits in ADHD Impact Developer Productivity]]—task initiation as an executive function difficulty at work.

### Trigger 3: Small Detached Tasks Do Not Become Habits

> "I can't do little, detached tasks. So building habits is a bust."

One reading, not yet captured or sourced in its own card: without a reward loop, repetition alone does not build the habit, so standard habit advice fits poorly.

- [[Reducing friction is a key strategy for building ADHD-friendly habits]]—a response that changes the obstacle instead of relying on repetition. [synthesizes:: [[Reducing friction is a key strategy for building ADHD-friendly habits]]]

### The Loop These Feed

A task with no anticipated reward feels too costly, it is avoided, and the unfinished "simple" task feeds shame.

- [[Executive Function Failures Trigger Shame-Driven Avoidance Loops in ADHD]]—the self-reinforcing shame and avoidance cycle. [synthesizes:: [[Executive Function Failures Trigger Shame-Driven Avoidance Loops in ADHD]]]
