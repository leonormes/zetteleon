## Cognitive Training Neurofeedback Mindfulness and Exercise Can Improve Executive Function

Summary: Evidence-backed interventions can improve specific executive function skills, though evidence strength varies by intervention and skill.

Details: Computerised cognitive training shows benefit for some children with learning disabilities on word memory and cognitive flexibility. Neurofeedback training—learning to regulate the brain activity that drives specific executive processes—has early evidence for improving cognitive flexibility. Mindfulness or meditation practice may help inhibitory control. Exercise that combines physical activity with real-time cognitive demand—such as team sports, which require working memory (tracking teammates), inhibitory control (resisting a bad shot), and cognitive flexibility (adapting to a substitution)—engages all three executive function domains at once.
