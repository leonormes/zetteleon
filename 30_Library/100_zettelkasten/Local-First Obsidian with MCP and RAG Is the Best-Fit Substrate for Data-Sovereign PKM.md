## Local-First Obsidian with MCP and RAG Is the Best-Fit Substrate for Data-Sovereign PKM

For a DevOps or infrastructure knowledge worker with a neuro-variable profile, a local-first plain-text Obsidian vault (Canvas, Excalidraw, ExcaliBrain, Bases) combined with a local MCP/RAG server is the superior 2026 stack versus cloud-native visual-thinking tools (Heptabase, Storyflow, Scrintal), because data sovereignty is non-negotiable for infrastructure knowledge, the vault-as-git-repository aligns with existing IaC workflows, and only a local Markdown substrate supports genuine MCP/RAG integration.

### Scope & Conditions

Cloud-native tools may offer stronger native canvas-wide AI context awareness (e.g. Storyflow) but sacrifice data sovereignty and local MCP/RAG integration entirely, which is the disqualifying factor for infrastructure and runbook knowledge.

### Evidence

> "Data sovereignty is non-negotiable for infrastructure knowledge (runbooks, credentials patterns, architecture decisions)… The vault as a local Git repository aligns with existing IaC workflows… MCP server integration provides the PCM architecture described in Vector 3."

### Implications

- The existing choice of a local Git-tracked Obsidian vault for infrastructure/PKM notes is the empirically best-supported option for this specific profile, not merely a personal preference.
- Any future tool evaluation should treat "local MCP/RAG integration" and "git-diffable plain text" as hard requirements, not nice-to-haves.
