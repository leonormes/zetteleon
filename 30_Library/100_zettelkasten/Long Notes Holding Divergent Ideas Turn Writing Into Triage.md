## Long Notes Holding Divergent Ideas Turn Writing Into Triage

When a note holding several ideas is pulled into a writing project, the writer has to edit out its complexity, so writing becomes triage. The source is Bob Doto, A System for Writing.

### Scope & Conditions

Doto's argument about using notes in a writing project; the cost falls at the moment of use, not when the note is made.

### Evidence

> "Whenever we pull a note into a writing project and have to edit out complexity, writing becomes triage."
> (Doto, A System for Writing, section "More is Less")

> "In short, long-notes containing divergent ideas create added steps and confusion."
> (Doto, A System for Writing, section "More is Less")

### Implications

- Time saved by writing one long note is paid back later as sifting.
- A note should arrive in a draft ready to be handled, not searched for the point it contains.
