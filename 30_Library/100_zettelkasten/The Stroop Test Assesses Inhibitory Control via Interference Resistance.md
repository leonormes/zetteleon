## The Stroop Test Assesses Inhibitory Control via Interference Resistance

Summary: The Stroop test is a concrete, named behavioural measure of the inhibitory-control domain of executive function.

Details: In the Stroop test, a person is shown a colour word (e.g. "red") printed in a mismatched ink colour (e.g. green) and asked to name the ink colour rather than read the word. Answering correctly requires inhibiting the automatic, well-practised urge to read the word and instead executing the less automatic instruction—making the test a direct behavioural measure of inhibitory control, one of the three core executive function skills. Clinicians, typically neurologists, use tests like this as part of a broader neurological exam to evaluate executive functioning.
