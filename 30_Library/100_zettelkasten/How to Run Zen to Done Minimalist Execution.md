## How to Run Zen to Done Minimalist Execution

Zen to Done (ZTD) is a minimalist execution loop that turns raw captures into focused daily action without heavy administrative overhead. By collecting all inputs, processing them decisively, selecting three Most Important Tasks (MITs), and single-tasking, it keeps execution aligned with intentional priorities.

### Scope & Conditions

Suited to daily personal execution and ADHD-friendly focus where complex multi-tier task taxonomies create friction. Larger multi-week projects still require external tracking once deferred out of the daily inbox.

### Evidence

Derived from the Zen to Done summary (Leo Babauta) in [[SoT - Intentional Living]] (§6).

### Implications

- Limiting daily priorities to three MITs forces genuine trade-offs before the workday fragments.
- Single-tasking pairs directly with [[The Sacred No - Intentionality as Habit Intervention]] to protect deep work blocks.
