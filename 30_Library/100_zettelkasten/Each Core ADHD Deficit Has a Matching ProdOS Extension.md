## Each Core ADHD Deficit Has a Matching ProdOS Extension

Each core ADHD deficit is answered by a specific extension in ProdOS, with volatile working memory by offloading, initiation paralysis answered by situated cues, time blindness by re-spatialising time, and overwhelm by distributed structure. ^claim

### Scope & Conditions

This is a design mapping for ProdOS, not a clinical claim. It does not say the matched extension works for every person.

### Evidence

This is a design mapping of my own, and no external source has been checked.

### Implications

- Volatile working memory: HEAD notes and aggressive externalisation capture state so working memory can be cleared.
- Initiation paralysis: templates and MVAs provide environmental triggers.
- Time blindness: time-blocking turns time into a physical container.
- Scatter and overwhelm: MOCs hold the architecture so attention can stay on the leaf node.
