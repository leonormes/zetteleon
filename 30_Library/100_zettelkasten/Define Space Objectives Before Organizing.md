### Define Space Objectives Before Organizing

Before organizing a space, define the exact tasks and workflows that need to be performed within it.

#### Scope & Conditions

Applies to any physical workspace redesign or optimization project.

#### Evidence

> "Before organising, define exactly what tasks need to be performed in the room"

#### Implications

- Prevents optimizing the space for the wrong workflow.
- Clarifies which items actually belong in the room and which should be removed.
