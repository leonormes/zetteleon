> [!claim] Statement
> The ADHD pull towards novelty supplies a short burst of motivation when a new tool or method is adopted, but the burst decays faster than a system can mature—so the same drive that starts a system also abandons it.

## Supporting Evidence

- New tools reliably produce excitement and hope; the report ties this to immediate dopamine reward.
- The excitement is short-lived, after which effort feels effortful again and the search restarts—the cyclic pattern named in [[System-Hopping]].

## Mechanism

- Reward is front-loaded onto _adoption_ (setup, fresh interface) rather than _use_, so a system is most rewarding precisely when it has done the least work.

## Counter-positions

- Some "hopping" is rational tool selection, not a deficit—you cannot know a tool's fit without trialling it.
- Novelty can be harnessed (new view, new template) to re-engage an existing system rather than replace it.

## Crux

- Whether a switch tracks a genuine fit problem or merely chases the adoption high. See [[Q - Iterating versus system-hopping]].

## Falsifier

- If users who deliberately rotated _within_ one system (new dashboards, themes) showed the same abandonment rate as those who switched tools, novelty would not be the operative driver.
