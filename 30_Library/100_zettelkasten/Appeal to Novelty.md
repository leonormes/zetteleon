- Definition: Assuming newer solutions are better simply because they're new
- Software Context:
  - Adopting new technologies without clear benefits
  - Rewriting working systems in trending frameworks
  - Choosing bleeding-edge over proven solutions

[[Decision making fallacies]]—*the stub hub this note sits under, alongside [[Sunk Cost Fallacy]].*

[[Novelty Effect]]—*the psychological phenomenon this fallacy exploits: mistaking novelty's genuine motivational pull for evidence that the new thing is actually better. Not the same claim—Novelty Effect describes a real, transient effect on engagement; this note describes the reasoning error of treating that effect as proof of merit.*
