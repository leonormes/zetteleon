## Network Graph Views Can Induce Apophenia Through Software-Drawn Connections

Visual network graph views in note-taking tools can induce apophenia—the human tendency to perceive meaningful connections between unrelated things—because the graph creates an impression that the system is doing the thinking, when the software is only visualising mechanical symbol-matching rather than genuine comprehension.

### Scope & Conditions

Applies to bidirectional-link network diagrams specifically, as distinct from the underlying explicit typed links a human authored.

### Evidence

> "The graph creates the illusion that the system is doing the thinking, but the software does not inherently comprehend the context; it merely visualizes mechanical symbol-matching."

### Implications

- A note appearing connected in a graph view is not by itself evidence the connection is meaningful; the typed edge and its rationale (not the line on the diagram) carries the actual claim.
