## Respect Is a Set of Agreed Actions and Not an Identity

Respect in a household is a set of specific agreed actions and not an identity claim such as being a nice person. ^claim

### Scope & Conditions

Applies to partners and parents who each believe they are respectful but define respect differently.

### Evidence

> "Respect is not an identity ("I am a nice person"); it is a set of specific, agreed-upon Actions."
> ([[SoT - Family Communication & Team Charter]], text before the 2026-11-24 refactor, §2)

This is my own reasoning, not an externally sourced finding. No outside source has been checked.

### Implications

- Write respect down as actions both partners have agreed to.
- Start the conversation by validating identity, then move to what respect looks like in practice.
