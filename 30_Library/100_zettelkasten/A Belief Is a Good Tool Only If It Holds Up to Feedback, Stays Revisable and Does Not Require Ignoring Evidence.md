## A Belief Is a Good Tool Only If It Holds Up to Feedback, Stays Revisable and Does Not Require Ignoring Evidence

A belief is a functional tool only if it meets all three criteria. It holds up to real-world feedback, it remains open to revision, and it does not require ignoring evidence. These guard utility-based belief selection against denial and magical thinking.

### Scope & Conditions

The three criteria are jointly necessary, which is the meaning of "only if", so they are kept as one test and not split into three notes. The test bounds the usefulness question in [[A Belief Can Be Chosen by Its Usefulness for a Goal, as a Carpenter Chooses a Tool]].

### Evidence

> "A belief is a good, functional tool only if it meets three specific criteria: 1. Holds up to real-world feedback: It leads to constructive, observable engagement with reality rather than fantasy. 2. Remains open to revision: It updates dynamically when new evidence or results emerge. 3. Does not require ignoring evidence: It rejects denial and magical thinking, grounding itself in reality-tested experience."
> (Nir Eyal, Beyond Belief, via an LLM summary; chapter and page not captured)

### Implications

- A belief that expands options but fails these criteria is not a good tool.
- Turns "is it useful?" into a question with a reality check attached.
