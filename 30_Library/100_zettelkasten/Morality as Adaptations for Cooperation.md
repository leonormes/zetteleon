## Morality as Adaptations for Cooperation

Morality is a set of psychological adaptations that allow otherwise selfish individuals to reap the benefits of cooperation. It is a functional toolkit that evolved, not an abstract truth.

### Scope & Conditions

A descriptive, scientific definition. Greene notes that calling this machinery "moral" is not an endorsement of it.

### Evidence

> "Morality is a set of psychological adaptations that allow otherwise selfish individuals to reap the benefits of cooperation."
> (Joshua Greene, Moral Tribes, Chapter 1, section "The Function of Morality")

### Implications

- Morality is treated as a functional toolkit that evolved, not as an abstract truth.
- Which features count as moral is decided by their function in enabling cooperation, not by whether they are admirable.
