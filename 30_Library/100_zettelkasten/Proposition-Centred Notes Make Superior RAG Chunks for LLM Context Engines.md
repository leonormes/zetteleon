### Proposition-Centred Notes Make Superior RAG Chunks for LLM Context Engines
The 2024-2026 shift in personal knowledge management reconceives the local plain-text vault not as a passive "second brain" queried by a human, but as a Personal Context Management (PCM) substrate for LLM context injection via RAG and MCP. Within this paradigm, proposition-centred notes (arguable claims) make more semantically dense, contextually retrievable RAG chunks than "What is X?" topical facts, and MOC architecture supplies relational context that pure vector search lacks.

#### Scope & Conditions
Assumes a local-first plain-text vault (e.g. Obsidian) as the substrate, chunked and embedded into a vector store, with a local MCP server exposing store, search, and query tools to MCP-compatible clients.

#### Evidence
> "Proposition-centred notes make superior RAG chunks: arguable claims provide more semantically dense, contextually retrievable units than 'What is X?' facts... The paradigm shift is from 'I search my notes' to 'my AI assistant reasons with my notes as its working memory.'"

#### Implications
- Writing notes as claims, not just definitions, improves both human cognitive leverage and machine retrieval quality simultaneously.
- MOCs are not purely a human-navigation aid; they also improve LLM retrieval by supplying explicit relational context.
