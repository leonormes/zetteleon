## reMarkable Paper Pro

An 11.8-inch colour digital-paper tablet used for handwriting, document annotation and focused reading. The owned setup includes Marker Plus and the Basalt UK Type Folio.

### Technical Details

| Area | Detail |
|---|---|
| Display | 11.8-inch Canvas Color display based on E Ink Gallery 3; 4:3 |
| Resolution | 2160 × 1620, 229 ppi |
| Colour | Approximately 20,000 rendered colours |
| Writing | 12 ms stated latency, 4,096 pressure levels, palm rejection |
| Lighting | Adjustable reading light |
| Processor | NXP i.MX 8M Mini, quad-core Cortex-A53 at 1.8 GHz |
| Memory and storage | 2 GB LPDDR4; 64 GB internal, about 46 GB user-available |
| Battery | 5,030 mAh; rated up to two weeks; 0–90% in 90 minutes |
| Connectivity | Dual-band Wi-Fi, USB-C 2.0 and accessory connector |
| Import formats | PDF and EPUB |
| Export formats | PDF, SVG and PNG |
| Dimensions | 274.1 × 196.6 × 5.1 mm |
| Weight | 525 g |
| Security | Device/in-transit/at-rest encryption, MFA, secure boot, passcode and auto-lock |
