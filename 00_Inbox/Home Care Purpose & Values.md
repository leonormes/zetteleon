## Optional Add-on: One-page Printable "Home Care Purpose & Values" (Kid-friendly, GTD-style)

Title: Home Care = Teamwork (so our house is calm)

Purpose (why we do this):

We look after our home together so it stays clean, safe, and easy to live in—and so everyone learns how to run their own home one day.

What we're practising (values):

- Fairness: Everyone helps. No one is the "default cleaner."
- Clarity: We agree what "done" looks like so we don't argue.
- Calm voices: We fix problems without shouting or blaming.
- Small steps: If something feels hard, we do the next tiny step.
- Respect: We treat each other kindly while we do boring jobs.

Vision (what success looks like):

Most days, the house resets quickly, we know what to do, and we have more time for fun with less stress.

Our simple rules (how we work):

1. We decide first, then do. (No guessing, no vague "tidy up.")
2. "Done" is visible. If it doesn't look finished, it isn't finished yet.
3. One reminder, then we check.
4. Parents don't quietly redo jobs. We help you learn, not replace you.
5. When it's done, it's done. We celebrate and move on.

Daily reset time: `____:____`

Weekend reset time: `____:____`

If you feel stuck (the next-action trick):

- Ask: "What's the _next_ tiny step?"
  Examples: "Pick up 5 items." "Put plates in the dishwasher." "Put clothes in the basket."

## Optional Add-on: 5-minute Family Check-in Script (Purpose → Principles → Next aCtions)

Use this at the daily reset time.

1. Purpose (10 seconds):
   "We're doing this so the house is calm and fair—and so everyone learns."

2. What 'done' looks like (30 seconds):
   "We're aiming for _clear surfaces, rubbish out, and things put where they belong_."

3. Who owns what (60 seconds):
   "Today, you've got `____`, you've got `____`, and I've got `____`."

4. Next tiny step (60 seconds):
   Ask each child: "What's your first tiny step?"
   If they don't know: give two choices: "Start with rubbish, or start with clothes?"

5. Check + finish (60 seconds):
   "Show me when you think it's done."
   If not done: "What's the one thing to fix?" (Say the smallest visible fix.)

6. Close (30 seconds):
   "Thanks. We did it. Screens / Wi‑Fi / relax time starts now (if that's the rule today)."
