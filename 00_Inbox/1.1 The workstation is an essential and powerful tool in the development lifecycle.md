# 1\.1 The Workstation is an Essential and Powerful Tool in the Development Lifecycle

The Dev workstation can modify the source code and push changes to production, therefore effecting the business in potentially dramatic ways.

I find it interesting to revisit the fundamental parts of the system as they lock us in to other choices further up the chain. As a simple example, the choice to use macOS means having to use an extra layer when dealing with containers. This also means subtle differences in software versions between development machines and production.

Choices in tooling make a difference to workflow. Running tests. Making small commits and so on.

The idea here is that the choice of dev workstation setup dictates other upstream choices.
