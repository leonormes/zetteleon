# I want to organise my interests and PKM so it is cross platform/tool functional and aligned. Research how to do this. I want to build a graph not an org chart as my knowledge and interests are wide but have a few cross cutting themes. I want to be able to identify the links more easil

Build a **Markdown-first labelled graph**: atomic notes as nodes, human-readable typed links as edges, and small independent facets such as `domains`, `themes`, and `kind`. Keep folders shallow and operational; use Obsidian Bases, local graphs, semantic search, and Maps of Content as different views over the same portable Markdown source.[^1][^2][^3]

The report provides the complete architecture, including:

- A minimal YAML schema and controlled vocabulary
- Eight recommended relationship types
- Cross-cutting theme and domain modelling
- Concrete Obsidian note templates
- MCP/LLM discovery and validation workflows
- Shell-based vocabulary auditing
- A phased migration plan for your existing vault
- CSV and JSON-LD export strategies

The key rule is: **semantic search proposes connections; reviewed typed links preserve them.**
