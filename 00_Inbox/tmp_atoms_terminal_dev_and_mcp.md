#### Atom 3: Model Context Protocol (MCP) Definition

- kind: definition
- statement: The Model Context Protocol (MCP) is a JSON-RPC based standardization layer that provides a unified interface for LLMs to interact with external data and tools across different AI clients.
- scope_and_conditions: Analogous to the Language Server Protocol (LSP) for development environments.
- evidence: "open-source standardization layer designed to resolve the fragmentation in how Large Language Models (LLMs) interface with external data and tools [Video 2]"
- implications:
  - Decouples tool-calling implementations from specific execution environments.
  - Allows "build once, deploy anywhere" for AI tool integrations.
- confidence: high
- tags: [mcp, standardization, interoperability, ai-infrastructure]

- scope_and_conditions: Defines the flow of information from the user interface to the tool execution environment.
- evidence: "interaction between the Host (client application), the Server (exposing tools/resources), and the LLM (reasoning engine) [Video 2]"
