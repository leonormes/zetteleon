Reading List: Types in Programming and Mathematics

I. Programming and Type Theory

Focus: Understanding types as sets and constraints within software design.

 - Programming With Types (Vlad Riscutia), Section 2.1.1: The Empty Type (Understanding types as sets).
 - Programming With Types, Chapter 3.4: Algebraic Data Types (Sum and Product types).
 - Programming With Types, Section 1.2.2: The Definition of Type Systems and allowed values.
 - Programming With Types, Chapter 4.1: Avoiding Primitive Obsession (Data-oriented design).
 - Programming With Types, Section 4.2: Enforcing Logic via Type Constraints.
 - Structure and Interpretation of Computer Programmes (SICP), Chapter 2.1.3: What Is Meant by Data?
 - SICP, Chapter 2.4: Multiple Representations and Generic Operations.
 - Programming With Types, Section 11.3.3: Higher Kinded Types and Category Theory.
II. Mathematics and Formal Logic
Focus: The underlying set theory and structural logic that define types.
 - Classic Set Theory, Chapters 1.2, 3.1–3.2: Formal Set Definitions and Constructions.
 - Mathematical Proofs, Chapter 1.1: Describing Sets and Elements.
 - The Unsolvable Problem, "Cantor's Set Theory": Philosophical and mathematical overview of sets.
 - Classic Set Theory, Chapters 4.1, 4.7: Zermelo-Fraenkel Axioms (The rules for set formation).
 - The Unsolvable Problem, "Formalism and Hilbert's Program": Axiomatic systems and formal verification.
 - Mathematical Proofs, Chapter 2: Symbolic Logic and Propositions.
 - The Mathematician's Brain, "STRUCTURES": Morphisms, Categories, and Functors.
 - Classic Set Theory, Chapter 2.3: Isomorphisms and Preserving Operations.
 - Mathematical Proofs, Chapter 15.1: Binary Operations and Algebraic Structures.
 - Thinking About Mathematics, Preface: The Philosophy of Mathematical Objects and Structures.
