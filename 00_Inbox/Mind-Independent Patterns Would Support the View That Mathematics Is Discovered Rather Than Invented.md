## Mind-Independent Patterns Would Support the View That Mathematics Is Discovered Rather Than Invented

If spatial and temporal patterns are fundamental, mind-independent features of the universe, as the block universe model suggests, that supports the Platonist view that mathematics is discovered. Mathematics is then the language used to describe structures that already exist.

### Scope & Conditions

Conditional on the patterns being mind-independent. The rival view is formalism, where mathematics is an invented set of rules and symbols.

### Evidence

> "If patterns (both spatial and temporal) are fundamental features of the universe (as in the block universe model), then this would support the idea that mathematics is discovered."
> (Gemini session, section Is Mathematics Invented or Discovered)

### Implications

- Calling time an illusion does not by itself make mathematics a human invention.
