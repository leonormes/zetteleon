## The MESH API Shared Secret — What It Is and Where Yours Is

### What "shared secret" means in MESH API context

The **shared secret** is a separate credential from the certificate/key pair you've been working on today. It's used to construct the **HMAC-SHA256 authentication token** that goes in the `Authorization` header of every MESH API HTTP request.

Every API call you make must include a header in this format:

```text
NHSMESH 8KM90HC001:nonce:1:timestamp:hmac_hash
```

The `hmac_hash` is computed as:

```python
import hmac, hashlib

shared_secret = "your-shared-secret"
message = f"{mailbox_id}:{nonce}:1:{timestamp}"
hash = hmac.new(shared_secret.encode(), message.encode(), hashlib.sha256).hexdigest()
```

The shared secret is **not the certificate password** (`fitfile_nhs`) and it's **not the private key**. It's a separate string credential tied to your mailbox, issued when the mailbox is provisioned.
