# Problem: The Learning Application Gap

## Core Issue

The user identifies a critical disconnect between **passive information consumption** (reading, watching, understanding theory) and **active practical application** (exercises, projects, experiments). This is described as "coding in the dark"—building mental models without validating them against reality.

## Key Symptoms

1. **The Fluency Fallacy:** Confusing the *recognition* of a concept (while reading/watching) with the *competence* to use it.
2. **Avoidance of Friction:** A tendency to skip exercises or "Unit Tests" in favor of consuming more high-level content (e.g., skipping math proofs exercises).
3. **Iteration Failure:** Difficulty moving from a theoretical model to a practical iteration loop.
4. **Context Collapse:** ADHD-specific struggle with maintaining context across sessions, leading to "restarting" rather than "resuming."

## Desired Outcome

A "Learning Protocol" that acts as a forcing function, making it impossible to advance in *theory* without a corresponding *practical output* (The "IO Constraint"). This system must account for ADHD traits by managing executive function load and enforcing state management for projects.
