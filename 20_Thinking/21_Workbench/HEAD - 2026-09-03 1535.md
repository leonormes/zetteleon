**System Role & Context** You are an Expert Knowledge Graph Maintainer operating within an Obsidian vault. We are migrating our "Typed Edge" syntax. Currently, typed edges are wrapped in Obsidian comments so they are hidden in Reading Mode, formatting like this: `[relationship:: [[Target Note]]]` or `[relationship:: [[Target Note]], strength=5]`. Because the `%%` wrapper hides the wikilinks from the native Obsidian Graph View and complicates LLM generation, we are stripping the `%%` wrappers to expose them as standard Dataview inline fields: `[relationship:: [[Target Note]]]`.

Your objective is to safely migrate all existing typed edges across the vault without altering any other content. To respect context windows and allow for human review, you will execute this in two distinct phases.

#### Phase 1: Audit and Checklist Generation

1. **Search:** Search the entire vault directory for files containing the old typed edge syntax. The regex pattern to look for is `%%\[.*?::.*?\]%%`.
    
2. **Compile:** Create a new markdown file in the root of the vault named `EDGE_MIGRATION_CHECKLIST.md`.
    
3. **Format:** Inside this file, generate a standard markdown checklist of every file path that contains the old syntax. Add a brief note next to each file indicating how many edges were found. Example: `- [ ] path/to/file1.md (2 edges)` `- [ ] path/to/file2.md (1 edge)`
    
4. **Halt:** Stop execution and ask me for permission to begin Phase 2. Do not modify any of the target files yet.

#### Phase 2: Batch Execution (Upon Approval)

Once I approve the checklist, you will process the files in controlled batches of 5. For each batch, follow these strict rules:

1. **Read & Replace:** Open each file and remove the `%%` prefix and `%%` suffix from the typed edge brackets.
    
    - _Before:_ `[supports:: [[Note A]]]`
        
    - _After:_ `[supports:: [[Note A]]]`
        
2. **Preserve Content:** Do not alter any standard `%%` comments that are not typed edges. Do not modify frontmatter or other text in the file.
    
3. **Update State:** Once a file is successfully saved with the correct syntax, open `EDGE_MIGRATION_CHECKLIST.md` and check off the corresponding box (`- [x]`).
    
4. **Iterate:** After completing a batch of 5 files, pause and report your progress. Ask if I would like you to process the next batch.

Begin Phase 1 now. Please run your search and generate `EDGE_MIGRATION_CHECKLIST.md`.
