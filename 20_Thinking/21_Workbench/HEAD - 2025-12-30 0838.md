Still trying to rethink IAC and gitops. In programming paradigms there are a number of ideas. OOP, DOP, type theory and so on. But with IaC we are limited in our thinking. I want more rigour like with the type theory, data oriented

How can we view a network? As a set of ips and a set of resources. The IPs map to resources.

But there are 2 sets of IPs. Public and private. Private IPs have restrictions.

IPs have reachability which varies based on public private.

There are DNS record and hostnames.

Certificates. They are for host identity.

The host identity and the proof go together. Fit some specific hostnames. The problem is the implementation is spread across boundaries. hostname in dns record certificate in a store. How can we represent this relationship/dependency in IaC and enforce it making broken config uncodable?
