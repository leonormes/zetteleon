The analysis refactor is complete. Summary of what changed:

## Module Structure

Replaced monolithic [`src/analysis.rs`](src/analysis.rs) with:

| Module | Role |
|--------|------|
| [`src/analysis/manifest.rs`](src/analysis/manifest.rs) | Pure YAML scanning + `ManifestScanResult` |
| [`src/analysis/metadata.rs`](src/analysis/metadata.rs) | `Chart.yaml` annotations scanning |
| [`src/analysis/helm.rs`](src/analysis/helm.rs) | `HelmExecutor` trait + reactive template repair |
| [`src/analysis/analyzer.rs`](src/analysis/analyzer.rs) | `HelmAnalyzer` orchestration + `ChartScanResult` |
| [`src/analysis/deep.rs`](src/analysis/deep.rs) | `perform_deep_analysis` + shared `analyze_images` |
| [`src/yaml_util.rs`](src/yaml_util.rs) | Shared `merge_values` / `construct_mock_value` (F01 dedup) |

## Visibility Improvements

- Unparseable images are collected in `unparsed` (not dropped silently)
- Warns on: empty strings, unrendered `{{ }}` templates, colon-garbage references
- `scan_only` prints unparsed refs and warnings
- `scan_blueprint` still returns `Vec<ImageReference>` for backward compatibility

## Tests

53 unit tests (up from 29), including 9 chart-pattern fixtures under [`tests/fixtures/analysis/`](tests/fixtures/analysis/).

Integration test: [`tests/analysis_integration.rs`](tests/analysis_integration.rs)—`#[ignore]` by default; run with vendored charts:

```bash
cargo test --test analysis_integration -- --ignored
```

Regenerate golden files after chart bumps:

```bash
cargo run --bin scan_only -- <chart-name> 2>/dev/null | tail -n +2 | sort > tests/fixtures/analysis/golden/<chart>.txt
```

## F02 Dedup

[`src/verifier.rs`](src/verifier.rs) now uses shared [`analyze_images`](src/analysis/deep.rs) instead of duplicating the compliance loop.

`cargo test`—53 passed, 1 ignored (integration). `cargo build`—clean.
