## Summary

A roadmap-level initiative to move the team from annual penetration testing to continuous security and maintenance as a first-class track, with dedicated capacity, quarterly goals, and measurable SLOs.

## Key Facts

- Current state is an annual pen-test cycle; the goal is a continuous security posture.
  > "I want to put the topic of security and maintance on the roadmap. currently it is not something the team even thinks about. They leave it up to a yearly pen test." — [[raw/2026-04-29-pieces-security-and-maintenance-roadmap]] (Pieces: 4fa0276d-6dae-48a4-9f7e-8b3b8431e634)
- Covers both Platform Security and Application Security, with quarterly goals and per-sprint capacity allocation.
  > "this needs to be a platform and application security. BOth quartly and sprint allocation." — [[raw/2026-04-29-pieces-security-and-maintenance-roadmap]] (Pieces: 4b15e9a5-1d3a-4663-b2ff-6e0ac790422e)
- Proposed operating model changes include 10–20% sprint capacity reservation, a weekly 30-min triage cadence, and a rotating Security & Maintenance Champion.
  > "10–20% of each sprint (or 1 day/week) is reserved for Security & Maintenance tickets" — [[raw/2026-04-29-pieces-security-and-maintenance-roadmap]] (Pieces: 2bb99982-828c-4126-9610-e25ac846b041)
- Four standing epics: Vulnerability Management, Platform Hardening, Backup/Restore + DR, and Security Hygiene in Delivery.
  > "Epic A — Vulnerability Management (continuous)... Epic B — Platform Hardening (quarterly increments)... Epic C — Backup/Restore + DR... Epic D — Security hygiene in delivery" — [[raw/2026-04-29-pieces-security-and-maintenance-roadmap]] (Pieces: 2dde824a-4759-467a-84db-100e7745db42)
