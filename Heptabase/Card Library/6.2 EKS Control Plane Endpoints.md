## 6\.2 EKS Control Plane Endpoints

## 6\.2 EKS Control Plane Endpoints

### Key Points

The API server and control plane are managed by AWS and are not directly visible in the user's VPC.

Control plane endpoints can be public or private.

Private endpoints are only accessible within the VPC;

Public endpoints can be accessed over the internet.
