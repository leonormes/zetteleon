# 8\.2 Inbound and Outbound Rules in Security Groups

## Key Points:

Security groups consist of both inbound and outbound rules

Inbound Rules control the incoming traffic, specifying allowed ports and IP addresses.

Outbound Rules control outgoing traffic, specifying which destinations and ports the resource can access.

The rules can be defined based on IP ranges, Other NSGs or other AWS resources.
