## Schema For Link Types

Here's a suggested schema for categorizing links:

- Hierarchical: is-a, part-of, subtype-of
- Causal: causes, leads-to, depends-on
- Associative: related-to, contrasts-with, analogous-to
- Epistemological: synthesis, refines, evidence-for, challenges
- Ontological: instance-of, subset-of, mutually-exclusive-with
- Rhetorical: premise-of, conclusion-from, clarifies
