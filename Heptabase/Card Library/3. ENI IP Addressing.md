### 3\. **ENI IP Addressing**

- **Definition**: An ENI gets an IP address from the subnet's range. This IP address identifies the ENI (and attached resource) on the network.

- **Reachability**: The ENI’s IP becomes reachable within the subnet and the entire VPC (depending on security settings).
