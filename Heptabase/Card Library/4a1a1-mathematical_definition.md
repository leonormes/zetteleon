# 4a1a1-mathematical_definition

Shannon’s entropy for a set of possible messages with probabilities is defined as:

H = - sum\_{i=1}^{n} p_i log_2(p_i)

If each message is equally likely, the entropy is higher because the uncertainty is greater.

If some messages are more likely than others, the entropy is lower because there's less uncertainty.
