## Purpose of Links

In a personal wiki, links primarily help to organize or categorize information. It's more like a directory that collects facts, concepts, and resources for easy access.

A Zettelkasten, on the other hand, uses links to capture relationships between ideas in ways that support deeper thinking. Instead of merely categorizing, these connections prompt insights and help ideas evolve.

By designing each link to reveal an association, contradiction, or extension, you create a dynamic network where ideas can spark new ideas.
