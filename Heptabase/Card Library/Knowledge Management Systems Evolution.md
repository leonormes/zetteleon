Key features of this example:

1. Relationship Types:

   - Supports (theoretical backing)

   - Extends (builds on existing work)

   - Contradicts (oppositional relationships)

   - Prerequisites (required knowledge)

   - Examples (concrete instances)

   - Methodological (research/process connections)

   - Parallel (similar concepts)

   - Develops (evolutionary connections)

   - Influences (impact relationships)

   - Reviews (analytical connections)

2. Metadata for each relationship:

   - Target note

   - Strength (1-5)

   - Context explanation

   - Review date

   - Confidence level

   - Additional type-specific fields

3. Quality Metrics:

   - Relationship count

   - Average strength

   - Review status

   - Confidence distribution

4. Review Information:

   - Last review date

   - Next review date

   - Review interval

   - Priority
