# 7\.4 ENIs And Security Groups

## Key Points

Each ENI is associated with security groups that control inbound and outbound traffic.
Security groups define the least-privilege access for traffic between instances and other VPC resources.
ENIs in private EKS clusters inherit security group rules that define how pods communicate within the VPC.
