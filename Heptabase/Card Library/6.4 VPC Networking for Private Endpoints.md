## 6\.4 VPC Networking for Private Endpoints

## 6\.4 VPC Networking for Private Endpoints

### Key Points

If using a private endpoint, the control plane is accessible only from within your VPC.

Ensure proper routing between worker nodes and the private API endpoint.

Use the VPC Console to inspect networking components like subnets, security groups, and ENIs.
