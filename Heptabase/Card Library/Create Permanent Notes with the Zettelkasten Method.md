# Create Permanent Notes with the Zettelkasten Method

The Routine: When creating a permanent note, follow these principles:
Atomicity: Each note should contain only one distinct idea, concept, or argument.
Clarity and Conciseness: Write in full sentences, using your own words to explain the idea. Be as clear and concise as possible.
Source References: If the note is based on a source, include a clear citation for easy retrieval.
Linking: Connect the new note to related notes in your Zettelkasten using the "idea compass" or other relevant connections.
Why it Matters: These practices make your notes more discoverable, reusable, and conducive to generating new connections and insights.
