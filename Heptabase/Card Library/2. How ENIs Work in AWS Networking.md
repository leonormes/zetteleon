## 2\. **How ENIs Work in AWS Networking**

ENIs are used for connecting EC2 instances to the VPC, which enables resources to communicate within the VPC and with external services. Here's how ENIs contribute to networking:

- **Multiple ENIs per Instance**: EC2 instances can have multiple ENIs, each with its own security groups and IP addresses, which allows for complex network configurations like dual-homed systems (with different subnets or security groups for different interfaces).

- **Network Separation**: ENIs enable network separation between different services by placing them on different ENIs, making it possible to implement distinct network traffic policies.

- **Traffic Routing**: ENIs are directly linked to the **subnet** in the VPC and help route traffic according to the **route tables** defined in the VPC.
