### Daily Workflow

1. **Morning**: Open Daily Note (core plugin)

   - Review yesterday's note

   - Check Project Hub's "Next Actions"

   - Set 1-3 intentions for today

2. **Throughout Day**: Use Daily Note for:

   - Quick captures (ideas, questions, resources)

   - Progress notes

   - Code snippets with \`\`\`terraform blocks

3. **End of Day** (5 minutes):

   - Update Project Hub's "Next Actions"

   - Add to "Progress Log"

   - Link any new reference notes
