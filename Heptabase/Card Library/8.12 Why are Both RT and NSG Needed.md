# 8\.12 Why Are Both RT and NSG Needed

- Route Tables ensure that traffic can reach the correct destination (e.g., between subnets or out to the internet). However, they don't determine whether the traffic is allowed or safe.

- Security Groups control the permissions for traffic. They ensure only the intended traffic can reach or leave a resource, but they don't dictate where traffic is sent.

Having both allows AWS to separate the concerns of routing traffic and securing traffic.

---

## Example

- Route Table: A subnet's route table sends all traffic destined for the internet (`0.0.0.0/0`) to the Internet Gateway.

- Security Group: The EC2 instance in that subnet may have a security group that only allows inbound HTTP (port 80) and SSH (port 22) traffic from specific IP addresses.

Both components work together to ensure that traffic is:

- Routed correctly (by the route table).

- Filtered for security (by the security group).
