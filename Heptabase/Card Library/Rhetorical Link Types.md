# Rhetorical Link Types

When linking notes based on their rhetorical or argumentative structure, you can identify how the ideas relate in an argumentative or expository context:

- "Premise-of": One note serves as a premise or foundation for an argument made in another.

- Example: "Note A (Premise 1)" is premise-of "Note B (Conclusion)."

- "Conclusion-from": One note is a conclusion drawn from another.

- Example: "Note A (Observation)" leads to "Note B (Conclusion)."

- "Clarifies" or "Explains": One note clarifies or explains the meaning of another.

- Example: "Note A (Detailed Explanation)" clarifies "Note B (Abstract Idea)."
