# 1\. View the History of Specific Lines in a File

To view the history of specific lines in a file, you can use the `git log` command with the `-L` option. This option allows you to specify the file and the lines you're interested in.

Bash

```sh
git log -L <start>,<end>:<file>
```

Replace `<start>` and `<end>` with the line numbers you want to track, and `<file>` with the path to the file.

For example, to view the history of lines 10-15 in the file `main.ts`, you would run:

Bash

```sh
git log -L 10,15:main.ts
```

This will show you all the commits that modified those lines, along with the changes that were made.

# 2\. Identify the Commit where Desired Lines Existed

Once you've viewed the history, you can identify the commit where the desired lines existed. You can use the commit hash to refer to this commit in later commands.

# 3\. Extract and Restore only Those Specific Lines

To extract and restore specific lines from a previous commit, you can use the `git checkout` command with the `-p` (patch) option. This option allows you to interactively select which changes you want to apply.

Bash

```sh
git checkout -p <commit> -- <file>
```

Replace `<commit>` with the hash of the commit you want to restore from, and `<file>` with the path to the file.

Git will then show you each change (or "hunk") from that commit and ask you if you want to apply it. You can choose to apply all changes, specific hunks, or even specific lines within a hunk.

To select specific lines, use the following options when prompted:

- `y`: Apply this hunk

- `n`: Don't apply this hunk

- `s`: Split this hunk into smaller hunks

- `e`: Manually edit this hunk

- `q`: Quit; don't apply any more hunks

# 4\. Verify the Restoration Was Successful

After applying the changes, you should verify that the restoration was successful. You can do this by:

- Inspecting the file to make sure the lines were restored correctly

- Running any relevant tests to ensure the code still works as expected

- Using `git diff` to compare the current state of the file with the previous commit

# Step 2: Identify the Desired Commit

From the `blame` output, note the commit hash for the version containing the desired lines.

---

# Step 3: Extract Specific Lines Using `git show`

The `git show` command displays file contents from a specific commit.

```bash
git show <commit>:<file>
```

To extract specific lines:

```bash
git show <commit>:<file> | sed -n '<start>,<end>p'
```

**Example:**

```bash

```

**Output:**


---

