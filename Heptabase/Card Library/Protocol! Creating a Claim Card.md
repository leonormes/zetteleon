# Protocol: Creating a Claim Card

1. State the claim in ONE sentence. Full sentence, not a topic.

2. Steel-man: is this the strongest version? Rewrite if not.

3. Falsifier: what observation or argument would prove this wrong?
   → If you cannot answer, the claim is not sharp enough. Rewrite or split.

4. Confidence: where on the epistemic ladder? (speculation → hypothesis →
   working belief → settled → public commitment)

5. Dated position: today's date + current view in one sentence.

6. Links: at least one `supports` or `contrasts-with` to existing claim.

7. Open threads: what do I not yet know that bears on this?

8. File under Concept hub.
