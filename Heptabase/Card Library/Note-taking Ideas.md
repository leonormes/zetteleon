## Note-taking Ideas

Defining the links between the notes is a priority A link can be considered complex when it adds a lot to the originating note, or has lots of further links. If it creates a long chain. A -> B -> C -> D or A -> B then B -> C, B -> D, B -> E.

Idea 1:

Link notes together somehow.

Idea 2: Builds on idea 1.

Add a description to the link to add context and describe why the ideas are

linked or the nature of the relationship.

Idea 3: Builds on 2,1

This should describe the link in a uniform way for later understanding. This

should be metadata about the link in a standardised format.

Link type. Is a bit confusing. Type of link is example. But the link is not the

example, the idea or content in the linked note is the example. So the link

type is the wrong thing to call it.
