## **What Is an Elastic Network Interface (ENI)?**

An **ENI** is a virtual network card that can be attached to an EC2 instance or other AWS resources. Each ENI can include:

- [Primary private IP address (and optional secondary private IPs)..md](Primary%20private%20IP%20address%20(and%20optional%20secondary%20private%20IPs)..md)

- [Public IP address (for instances with internet access)..md](Public%20IP%20address%20(for%20instances%20with%20internet%20access)..md)

- [Security groups attached to the ENI..md](Security%20groups%20attached%20to%20the%20ENI..md)

- [MAC address for identifying the interface..md](MAC%20address%20for%20identifying%20the%20interface..md)

- [One or more Elastic IP addresses (for static public IP addresses)..md](One%20or%20more%20Elastic%20IP%20addresses%20(for%20static%20public%20IP%20addresses)..md)

ENIs can be attached, detached, or reassigned across instances within the same Availability Zone, providing flexibility in network configurations.

ENIs (Elastic Network Interfaces) are virtual counterparts to physical network interface cards (NICs).
