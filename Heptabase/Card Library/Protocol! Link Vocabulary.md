## Protocol: Link Vocabulary

Node tags (one per card)

`#claim`—contested propositions (JTB)

`#concept`—named phenomena (IOED)

`#practice`—protocols you execute (Feynman Technique)

`#source`—papers, books, talks (Rozenblit & Keil 2002)

`#person`—thinkers (Gettier, Williamson)

`#question`—open threads you are chasing

Link types (in the ## Links block at the end of each card)

- prerequisite-of—"you need the source to understand the target"
- instance-of—"target is a specific case of source"
- contrasts-with—"meaningfully opposed"
- supports—"source is evidence for target"
- related-to—escape hatch; use sparingly

### Rules

1. One node tag per card. No exceptions.
2. Five link types. No additions without editing this card.
3. Direction is always source → target.
4. When tempted to invent a new type, use related-to instead.
5. Do not retrofit old cards. Typing applies from today forward.
