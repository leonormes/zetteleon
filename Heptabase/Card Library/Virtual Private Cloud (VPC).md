# Virtual Private Cloud (VPC)

A **VPC (Virtual Private Cloud)** is a logically isolated virtual network where you can define [subnets](https://app.heptabase.com/c16a6d60-49a6-4aec-9d1a-6161cbbe31a8/card/5eb3c92e-d5d1-44ac-bbe0-0ae977052a95), route tables, and security groups to control traffic. Think of the VPC as the entire network space where your AWS resources (EC2 instances, RDS databases, etc.) live and communicate.
