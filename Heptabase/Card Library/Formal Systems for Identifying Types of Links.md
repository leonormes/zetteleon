# Formal Systems for Identifying Types of Links

To systematically categorize links between notes, you can adopt formal systems like RDF (Resource Description Framework) or OWL (Web Ontology Language):

- These systems allow you to define formal relationships (properties) between subject (Note A), predicate (relationship), and object (Note B), enabling a structured approach to link classification.

- For example:

- Subject: "Note A" (Graph Theory)

- Predicate: "is-part-of"

- Object: "Note B" (Mathematics)
