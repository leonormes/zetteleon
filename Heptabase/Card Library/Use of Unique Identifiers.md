## Use of Unique Identifiers

- Each Zettel should have a unique identifier, such as a number or code. This makes it easier to create links between notes and to track the relationships between them. In practice, this means assigning a unique ID to each Zettel as you create it. You can then use these IDs to create links between notes, even if you're using a simple text editor that doesn't support backlinking.
