# 8 Overview of AWS Security Groups

# 8\.1 Overview of AWS Security Groups

## Key Points

Security groups act as virtual [firewalls](8.8%20Introduction%20to%20Firewalls.md) to control inbound and outbound traffic at the instance or resource level.

They operate at the instance level within a VPC, unlike NACLs, which operate at the subnet level.

Stateful in nature: allowing inbound traffic automatically permits the response outbound.
