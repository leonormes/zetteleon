## 7\.3 VPC CNI Plugin and ENIs

7\.3 VPC CNI Plugin and ENIs

### Key Points

- The VPC CNI plugin manages ENIs on worker nodes to allocate IPs to pods, allowing them to have VPC-native networking.
- Pods running on an EKS worker node share IPs from the ENI attached to that node, providing direct connectivity within the VPC.
