# Too Concrete

What I am trying to avoid is the concrete. I don't like having something that is set in stone that other things then are produced from. It means the thing set in stone is a dependency that needs to be accurate.

For instance, in programming it is bad practices to hard-code strings and things into the code. It makes the code inflexible. Instead, we abstract the input information to variables. That way, the same function can be used for many different inputs.
