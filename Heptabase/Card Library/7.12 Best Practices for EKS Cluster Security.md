# 7\.12 Best Practices for EKS Cluster Security

## Key Points

Apply least-privilege security group rules to ENIs for pod-to-pod and worker node communication.

Regularly audit EKS network policies and security groups to maintain a secure environment.

Ensure private EKS clusters use private endpoints and restrict public access.
