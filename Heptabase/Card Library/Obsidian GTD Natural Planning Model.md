### Practical Obsidian Usage

- **Simple Folder Structure:** Keep it minimal. Consider folders like:

   - `Projects`: For Project Hub notes.

   - `Resources`: For general learning notes.

- **Wikilinks:** Use `[[wikilinks]]` extensively to connect related notes.

- **Tags:** Use tags sparingly for broad categories (e.g., `#terraform`, `#gitops`, `#aws`).

- **Markdown Tasks:** `- [ ]` for actionable items. Use due dates for accountability.

- **Core Plugins:**

   - **Daily Notes:** Useful for capturing daily learning points or tasks related to your projects. Link daily notes to relevant Project Hub notes.

### Tech Learning Relevance

- **Code Snippets:** Use Markdown code blocks (\`\`\`\`) to embed Terraform code, Git commands, or configuration examples directly in your notes.

- **Documentation Links:** Link directly to relevant documentation pages (as shown in the examples above).

- **Learning Points:** Capture key learning points in your notes. Use callouts (`> [!NOTE]`) to highlight important concepts.

- **Example:** 

   ```null
   > [!NOTE] Terraform state is crucial for tracking infrastructure. Store it remotely (e.g., in AWS S3) for collaboration and reliability.
   
   ```
