# ADHD-Specific Strategies

- **Capture Triggers**: Create keyboard shortcuts for quick capture

- **Visual Cues**: Use emoji in note titles (🔄 for active, ✅ for complete)

- **Time Boxing**: Set 25-minute focus sessions with specific goals

- **Momentum Maintenance**: Break tasks into 10-minute chunks

- **Overwhelm Prevention**: Limit "Next Actions" to 3 items maximum
