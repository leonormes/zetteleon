## There is of Course the Luhmann-ID

You create some kind of arbitrary hierarchy wherein each Zettel has a place where it could be. Using a paper-based Zettelkasten, I recommend using this technique because it helps to deal with its organisation. The other types of ID wouldn't work as well for paper.
