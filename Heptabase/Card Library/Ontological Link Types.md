## Ontological Link Types

Borrowing from formal ontologies and knowledge representation, we can categorize links based on ontological roles:

- "Instance-of": One note represents a specific instance or occurrence of a more general concept.
- Example: "Note A (Individual Car)" is an instance-of "Note B (Car Category)."
- "Subtype-of": One note is a more specific subtype or variant of another concept.
- Example: "Note A (Electric Vehicle)" is a subtype-of "Note B (Vehicle)."
- "Analogous-to": One note draws an analogy or comparison to another, showing similar structure or behavior.
- Example: "Note A (Tree Data Structure)" is analogous-to "Note B (Family Tree)."
- "Subset-of": One note is a subset or specialization of another note.
- Example: "Note A (Prime Numbers)" is a subset-of "Note B (Natural Numbers)."
- "Mutually-exclusive-with": The two notes represent ideas that are incompatible or contradictory.
- Example: "Note A (Newtonian Physics)" is mutually-exclusive-with "Note B (Quantum Physics)."
