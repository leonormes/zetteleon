## Purpose

Human-readable specs for ProdOS Operon filters. **Live filters** are stored in `.obsidian/plugins/operon/data.json` and surfaced in [[Operon Dashboard]] via `operon` code blocks.

Edit filters in Obsidian: **Operon → Filters**, or adjust `data.json` and reload.
