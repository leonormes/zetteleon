[[BookFusion/Books/Continuous Delivery Pipelines How to Build Better Software Faster-3531204|Continuous Delivery Pipelines: How to Build Better Software Faster]]

Date Created: 2023-11-08 21:06:10 UTC

> We _build quality in_ through continuous evaluation of our software to give the developer a high level of confidence that their code is good. One passing test, or series of positive tests, is not enough to tell us that our code is good. But just one _failing_ test tells us the our code is not good enough. We follow the scientific principle of _falsifiability_ and test our code in order to reject it. If one test fails we will reject that Release Candidate and revert to the previous version of the system
