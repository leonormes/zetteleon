[[BookFusion/Books/Prometheus Up & Running-3531538|Prometheus: Up & Running]]

Date Created: 2023-09-22 21:15:07 UTC

> For all these features and benefits, Prometheus is efficient and simple to run. A single Prometheus server can ingest millions of samples per second. It is a single, statically linked binary with a configuration file. All components of Prometheus can be run in containers, and they avoid doing anything fancy that would get in the way of configuration management tools. It is designed to be integrated into the infrastructure you already have and built on top of, not to be a management platform itself.
