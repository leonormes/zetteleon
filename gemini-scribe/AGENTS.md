# AGENTS.md

This file provides context about this Obsidian vault for AI agents.

## Vault Overview

This vault is a comprehensive 'Life OS' and high-level technical operating manual, serving as a professional workbench for cloud infrastructure (Azure/AWS), systems architecture, and software engineering. It functions as a structured repository for moving information from chaotic capture into authoritative 'Sources of Truth' (SoT), integrating complex technical documentation with personal development and ADHD-specific productivity frameworks.

With over 1,700 markdown files, the vault represents a mature knowledge graph that balances deep technical forensics (e.g., FFNode and FITFILE analysis) with philosophical inquiry and systems thinking.

## Organization

The vault utilizes a strict numerical prefix system to manage the lifecycle of information, transitioning from active intake to permanent reference.

- **00_Inbox & 20_Thinking**: Initial capture and active drafting. The `21_Workbench` is the core engine for ongoing technical investigations (e.g., Azure VNet debugging, CIDR conflict resolution, and Type Theory analysis) and conceptual drafting.
- **01_journals**: Contains a disciplined daily logging practice (`Dailies`) that interlinks tasks with project notes, providing a chronological record of technical decision-making.
- **10_System**: The vault's 'engine room' containing specialized LLM prompts (e.g., 'Knowledge Consolidation Agent', 'The Magpie Writing Coach'), templates, and metadata schemas like the 'SoT' fileClass.
- **30_Library**: The permanent repository containing over 1,500 files. It is split into atomic conceptual notes (`100_zettelkasten`), categorised projects (`200_projects`), navigational hubs (`MoC`), and definitive protocols (`SoT`).
- **02_bases & 400_indexes**: High-level dashboards (e.g., 'Life OS Dashboard') and task lists for top-down visibility and navigation across the graph.
- **99_Archive**: Stores processed information, including a `Processed_By_Agent` subfolder for tracking AI-assisted outputs and historical technical comparisons.
